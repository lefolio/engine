# Packaging `@lefolio/engine`

This repository is the **npm engine** (`@lefolio/engine`). Consumer sites (including [lefolio.md](https://github.com/lefolio/lefolio.md)) keep their own `Content/` and their own Next.js app.

## What gets published

Included (see `package.json` `"files"`):

- `scripts/` — `lefolio` CLI (`bin`)
- `scaffold/` — copied by `lefolio init`
- `src/` — content, SEO, and markdown libraries (tests excluded via `!src/**/*.test.ts`)

Excluded: `public/` (synced assets are generated by `lefolio sync`), `.next/`, `out/`, `.github/`, design notes.

An empty `public/` is created at sync time; it does not need to ship in the tarball.

## Local development against the engine

From a site:

```json
{
  "dependencies": {
    "@lefolio/engine": "file:../lefolio",
    "next": "^16.4.2",
    "react": "^19.1.0",
    "react-dom": "^19.1.0"
  },
  "scripts": {
    "dev": "lefolio dev",
    "build": "lefolio build"
  }
}
```

```bash
npm install
npm run dev
```

- Content defaults to `<cwd>/Content` (override with `--content` / `LEFOLIO_CONTENT`).
- `lefolio dev` and `lefolio build` run Next in the site directory. The site owns `app/` and `next.config.ts`.
- Next, React, and Tailwind are peer dependencies. The site installs them.
- A `file:` install of this checkout also has its own `@types/react`. `lefolio dev` / `lefolio build` point the site's copy at the engine's so TypeScript sees one React.

Swap to a released version before publishing the site:

```json
"@lefolio/engine": "0.5.0"
```

Requires Next.js 16, installed by the site. Production builds default to `--webpack`; pass `--turbopack` to opt in.

## Dry-run the tarball

```bash
npm run pack:dry
# or
npm pack --dry-run
```

## First npm publish (maintainers)

1. Create/join the npm org **`lefolio`** (matches `@lefolio/engine`).
2. `npm login`
3. Confirm package contents: `npm pack --dry-run`
4. From a clean tree on `main`:

```bash
npm publish --access public
```

(`publishConfig.access` is already `public` for the scoped name.)

5. Tag the release: `git tag v0.5.0 && git push origin v0.5.0`

Bump `"version"` in `package.json` for each release (semver).

## CLI entry

```text
npx @lefolio/engine …     # after publish
npx lefolio …             # when bin is linked via dependency
node scripts/lefolio.mjs  # inside this repo
```

Commands: `init` | `sync` | `dev` | `build`. Extra flags after the command (e.g. `--turbopack`) are passed to Next.
